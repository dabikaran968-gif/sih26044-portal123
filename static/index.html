SIH26044 Solution Architecture & NLP Logic

High-performance AI engine implementing National Skills Qualification Framework (NSQF) ontology, semantic NLP parsing, and cosine similarity vector matching.

1

Resume Parsing & NER

Streams PDF bytes via pypdf, segments sections (Education, Projects, Experience, Skills), and extracts candidate metadata.

2

Explicit & Implicit Extraction

Maps explicit tokens to canonical NSQF skills (e.g., "ReactJS" → "React"). Applies NLP inference rules to extract implicit skills (e.g., "FastAPI REST" → Python + APIs).

3

Vector Gap & Explainability

Calculates weighted match overlap ($\text{Mandatory } w=3.0$, $\text{Preferred } w=1.0$), categorizes into Best Fit, Stretch, or Safe, and recommends curated SWAYAM/NPTEL roadmaps.

# Matching Formula:
MatchScore = min(100, max(15, ( ∑(Matched_Req × 3) + ∑(Matched_Pref × 1) ) / ( ∑(Total_Req × 3) + ∑(Total_Pref × 1) ) × 100))
